Voiceover generation

Gemini TTS က script ကို WAV အဖြစ်ထုတ်ပြီး GitHub မှာ host လုပ်ပါမယ်။ 1500 char ကျော်ရင် အလိုအလျောက် chunk ခွဲပါတယ်။
V2 flow. Audio ကို Gemini က transcribe လုပ်တယ် → Detect Pauses က ffmpeg နဲ့ တကယ့်တိတ်ဆိတ်ချိန်တွေတိုင်းတယ် → Scene Compiler က "။" တစ်ခုချတိုင်း scene တစ်ခုခွဲပြီး timing ကို pause တွေဆီ snap လုပ်တယ် → Gemini က scene တစ်ခုချင်းစီအတွက် visual direction ပဲပေးတယ်။ Scene ခွဲတာ AI မဟုတ်တော့ပါဘူး။
